# 1.0.0
- First release: connect with TextMeFlow in one click, QR code in the administration, test message and disconnect.
- WhatsApp messages for order placed, payment received, in progress, shipped, completed and cancelled, plus an optional message to the shop owner.
- Opt-in checkbox at checkout; customers only receive messages with their consent.
- Messages are sent through the Shopware message queue. Default texts in nl, en, fr and de.
