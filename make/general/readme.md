TextMeFlow sends WhatsApp messages from your own WhatsApp number through the TextMeFlow API (EU-hosted).

Setup: create a free account at https://textmeflow.eu, link your WhatsApp number (WhatsApp > Settings > Linked devices), copy your API key from the portal and paste it in the connection.

Message text and phone numbers are sent to TextMeFlow (Fades Management EOOD, Bulgaria). Privacy: https://textmeflow.eu/legal/privacy. Terms: https://textmeflow.eu/legal/terms. Only message people who agreed to receive WhatsApp messages from you.
